# Abravely Front

Base visual preservada do Chatzin, isolada do backend Rails/Chatwoot.

## Executar

```bash
corepack pnpm install
corepack pnpm dev
```

O frontend abre no endereço informado pelo Vite. As integrações de login, conversas e WhatsApp serão conectadas ao novo backend Abravely nas próximas etapas.
